# Apocalyptic Room

Juego 3D muy básico en primera persona, pensado como una experiencia de exploración sin enemigos.

## Incluye
- Mapa mediano: una habitación grande de 30 x 22 metros.
- Cámara en primera persona con Pointer Lock.
- Movimiento WASD y sprint con Shift.
- Ambiente post-apocalíptico: ventanas rotas, muebles abandonados, escombros, óxido, polvo, luces que fallan y niebla.
- Sin enemigos ni combate.
- Funciona como página web estática.

## Controles
- **W A S D:** mover
- **Shift:** correr
- **Mouse:** mirar
- **Esc:** liberar el cursor

## Ejecutar
Abre `index.html` en un servidor web local o publícalo con GitHub Pages.

La escena utiliza Three.js desde CDN.
